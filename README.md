# Python Bug Fixing Examples

A small set of corrected Python examples covering palindrome checking and safe average calculation.

## Run
```bash
python3 main.py
```

## Problems addressed
- Palindrome checking should compare the normalized string with its reverse.
- Average calculation should handle an empty list rather than divide by zero.

## Concepts practiced
- String normalization and slicing
- Functions and return values
- Exceptions and validation

To make this your own debugging project, document the original bug, expected behavior, actual behavior, and how you tested the fix.
